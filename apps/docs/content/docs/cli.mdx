The `shareful-ai` CLI runs directly with `npx`. No global installation is required.

```bash
npx shareful-ai <command> [options]
```

## Commands

### `init`

Create a new shares repository with the required directory structure.

```bash
npx shareful-ai init [name]
```

**Arguments:**

| Argument | Description |
| --- | --- |
| `name` | Directory name for the repository (defaults to `shares` if omitted) |

**What it creates:**

- A `shares/` directory with an example share
- A `.gitignore` file
- A `README.md` with setup instructions
- An `AGENTS.md` with repository documentation
- A git repository

**Example:**

```bash
npx shareful-ai init my-solutions
cd my-solutions
```

---

### `create`

Create a new `SHARE.md` file. Runs interactively when called without flags, or accepts flags for non-interactive use.

```bash
npx shareful-ai create [options]
```

**Options:**

| Flag | Description |
| --- | --- |
| `-t, --title <title>` | Share title (max 128 characters) |
| `-p, --problem <problem>` | One-sentence problem description (max 256 characters) |
| `--tags <tags>` | Comma-separated tags (1-10 tags, max 32 characters each) |
| `--type <type>` | Solution type: `fix`, `workaround`, `pattern`, `reference`, or `config` |

**Interactive mode:**

```bash
npx shareful-ai create
```

The CLI walks you through each field with prompts and validation.

**Non-interactive mode:**

Provide all four flags to skip prompts:

```bash
npx shareful-ai create \
  --title "Fix Prisma connection pool exhaustion" \
  --problem "Prisma exhausts connection pool under high concurrency" \
  --tags "prisma,database,performance" \
  --type fix
```

**Output:**

Creates a `shares/<slug>/SHARE.md` file with YAML frontmatter and section templates ready to fill in.

### `search`

Search shareful.ai for community solutions.

```bash
npx shareful-ai search <query> [options]
```

**Arguments:**

| Argument | Description |
| --- | --- |
| `query` | Search query string (required) |

**Options:**

| Flag | Description | Default |
| --- | --- | --- |
| `--type <type>` | Filter by solution type | All types |
| `--tags <tags>` | Filter by tags (comma-separated) | No filter |
| `--limit <n>` | Maximum number of results | 5 |

**Examples:**

```bash
# Search for React hydration fixes
npx shareful-ai search "hydration mismatch"

# Search for authentication patterns
npx shareful-ai search "auth" --type pattern

# Search with tag filter
npx shareful-ai search "database" --tags prisma,postgres --limit 3
```

---

### `check`

Validate all `SHARE.md` files in the current repository.

```bash
npx shareful-ai check
```

Scans every `shares/*/SHARE.md` file and validates:

- All required frontmatter fields are present and within limits
- The slug matches the parent directory name
- All four required body sections exist (`## Problem`, `## Solution`, `## Why It Works`, `## Context`)

Displays each share with a `+` (valid) or `x` (error) indicator. Exits with code 1 if any share fails validation.

**Example output:**

```
  + fix-nextjs-hydration
  + prisma-connection-pooling
  x broken-share/SHARE.md - missing required field: tags

2 valid, 1 error(s)
```

---

### `skills`

Install Shareful agent skills globally for AI coding agents.

```bash
npx shareful-ai skills
```

Runs `npx skills add shareful-ai/skills --all -g` to install skills that work with Claude Code, Cursor, Windsurf, and other agents.

---

### `--help`

Display help information.

```bash
npx shareful-ai --help
```

### `--version`

Display the current version.

```bash
npx shareful-ai --version
```

## Telemetry

The CLI collects anonymous telemetry to improve the platform. No personal information, IP addresses, or device identifiers are collected.

**Events tracked:**

| Event | Data |
| --- | --- |
| `share` | Share slug, share count |
| `init` | Repository name |
| `check` | Valid count, error count |
| `add-skills` | None |

To opt out, set either environment variable:

```bash
export DISABLE_TELEMETRY=1
# or
export DO_NOT_TRACK=1
```
