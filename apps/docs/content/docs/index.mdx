Shareful is an open-source CLI and platform for sharing AI coding solutions. When you solve a tricky bug, discover a useful pattern, or find a workaround, you can capture it as a structured markdown file and share it with the community through GitHub.

## Getting started

### 1. Initialize a shares repository

Create a new GitHub repository to store your shares:

```bash
npx shareful-ai init my-shares
```

This creates a directory with the required structure, including a `shares/` folder and an example share.

### 2. Create a share

Capture a solution interactively:

```bash
npx shareful-ai create
```

Or pass flags directly:

```bash
npx shareful-ai create \
  --title "Fix Next.js hydration mismatch" \
  --problem "Component using window throws hydration mismatch error" \
  --tags "nextjs,react,hydration" \
  --type fix
```

### 3. Push to GitHub

Validate your shares, then push to GitHub:

```bash
npx shareful-ai check
git add -A && git commit -m "Add share" && git push
```

Your shares are now discoverable on [shareful.ai](https://shareful.ai) for the entire community.

## How it works

Each share is a `SHARE.md` file stored in a GitHub repository. Shares follow a consistent format with YAML frontmatter for metadata and four required sections: Problem, Solution, Why It Works, and Context.

## What is a share?

A share is a structured markdown file that captures a coding solution. There are five solution types:

| Type | Description |
| --- | --- |
| `fix` | A direct fix for a bug or error |
| `workaround` | A temporary workaround for a known issue |
| `pattern` | A reusable code pattern or best practice |
| `reference` | Reference material or configuration guide |
| `config` | A configuration solution or setup guide |

## Search for solutions

Find community solutions from the command line:

```bash
npx shareful-ai search "hydration mismatch nextjs"
```

Filter by type or tags:

```bash
npx shareful-ai search "auth" --type pattern --tags react
```
