Shareful is an open-source CLI that ships two agent skills for sharing AI coding solutions. Capture fixes, patterns, and workarounds as structured markdown in GitHub repos — your agents discover them on-demand. This page shows you how to get set up, create your first share, and search for existing solutions.

## Getting started

### Why skills, not MCP?

Agent skills are plain CLI tools your agent calls directly. No server to run, no protocol negotiation, no extra dependencies. Shareful ships two:

- **shareful-search** — finds community solutions mid-conversation
- **shareful-create** — guides agents through capturing a fix

Run `npx shareful-ai skills` and both install in seconds.

### 1. Initialize a shares repository

Create a new GitHub repository to store your shares:

```bash
npx shareful-ai init my-shares
```

This creates a directory with the required structure, including a `shares/` folder and an example share.

### 2. Create a share

Capture a solution interactively:

```bash
npx shareful-ai create
```

Or pass flags directly:

```bash
npx shareful-ai create \
  --title "Fix Next.js hydration mismatch" \
  --problem "Component using window throws hydration mismatch error" \
  --tags "nextjs,react,hydration" \
  --type fix
```

### 3. Push to GitHub

Validate your shares, then push to GitHub:

```bash
npx shareful-ai check
git add -A && git commit -m "Add share" && git push
```

Your shares are now discoverable on [shareful.ai](https://shareful.ai).

## Search for solutions

Find community solutions from the command line:

```bash
npx shareful-ai search "hydration mismatch nextjs"
```

Filter by type or tags:

```bash
npx shareful-ai search "auth" --type pattern --tags react
```
